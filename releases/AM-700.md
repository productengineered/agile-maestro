## Summary

Closes the 48-field gap between task template metadata and what the Detail Panel UI renders. As the app was built through earlier epics, the bug and techdebt task templates evolved significantly — new fields were added for severity, RCA tracking, regression risk, business justification, and more. The UI never caught up with those template changes, so we jumped ahead to AM-700 to address this before it compounded further (hence no AM-600 in sequence). Bug and TechDebt types now have dedicated overview views with type-specific cards. Epics show goal hero cards. Timestamps, blocks relationships, and agent assignments are visible across all task types. Stats bars have full context pills, and the comments tab gained count badges and filtering.

With AM-700 complete, we'll return to Phase 6 of the initial plan as AM-600 to close out the original app build scope.

## What's New

### Bug & TechDebt Model Parity (AM-701)
- 16 new optional fields decoded in TaskSpecificMetadata
- Bug fields: severity, stepsToReproduce, expectedBehavior, actualBehavior, rcaStatus, affectedFiles, environment, discoveredFrom, discoveredBy
- TechDebt fields: debtType, debtCategory, regressionRisk, impactIfDeferred, businessJustification, filesAffected
- Shared fields: createdAt, lastUpdatedAt, createdBy

### BugOverviewContent (AM-702)
- Dedicated bug view with severity badge and RCA status chip
- Steps to Reproduce as numbered list with bullet-to-number normalization
- Expected vs Actual behavior side-by-side cards
- Environment card, Discovered From/By cards, Affected Files
- Parent Story card for bugs under a story

### TechDebtOverviewContent (AM-703)
- Dedicated techdebt view with Classification card (debt type + category)
- Regression Risk card, Files Affected, Impact if Deferred
- Business Justification card, AI Execution Hints disclosure group
- Parent Story card, Assigned To card, Discovered By chip

### Cross-Cutting Enhancements (AM-704)
- BlocksCard on all 5 overview types with clickable navigation
- EpicGoalCallout hero card as first item in epic Overview
- Header metadata row with claimed_by agent (avatar + relative time) and timestamps
- AI Execution Hints label fix (was "Affected Files") + visual de-emphasis
- Live-updating relative timestamps via TimelineView

### Stats Bar & Tab Enhancements (AM-705)
- Epic stats: SPRINT, SIZE, RISK pills
- Story stats: TASKS child count, SPRINT pills
- Removed duplicate priority pill from task/bug/techdebt stats bar
- StatsBarView empty guard — only renders when there are visible pills
- Comment count badge on Comments tab pill
- All/Rejections filter toggle in CommentsTabView

### Integration Tests (AM-706)
- End-to-end JSON decoding tests for all task types (bug, techdebt, epic, story, task)
- View rendering tests for BugOverviewContent, TechDebtOverviewContent, and enhanced views
