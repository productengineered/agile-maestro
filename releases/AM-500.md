## Summary

Replaces the Team View placeholder with a full NavigationSplitView containing three sections: a grouped agent roster with search and expandable cards, a horizontal train map visualizing Epic/Story/Task workflow pipelines, and a directory health dashboard with animated metric counters. The ManifestService was rewritten from Python to native Swift, eliminating the external dependency.

---

## What's New

### Team View Shell
- NavigationSplitView with Liquid Glass sidebar
- Three navigation sections: Team Roster, Workflow, Directory Health
- Empty states for no toolkit configured (ERR-TV-001), no manifest (ERR-TV-002), and errors (ERR-TV-003)
- "Open Product Settings" button wired to Edit Product sheet

### Agent Roster (Team Roster section)
- Agents grouped by role category: Core Team, Specialists, Security
- Expandable agent cards with collapsed state (avatar, name, model indicator, skill count) and expanded state (full description, skill chips via FlowLayout, tools list, MCP servers, file path)
- Live search filtering across agent name, description, and skills (case-insensitive)
- Accordion behavior: expanding one card collapses others (SM-TEAM-003)
- Stagger animation at 40ms per card on first load with reduce-motion support

### Workflow Train Map (Workflow section)
- Three pipeline sections: Epic (8 stages), Story/Bug/TechDebt (5 stages), Task (3 stages)
- Colored circle nodes (22pt) connected by horizontal lines
- Stage names above nodes, agent names below
- First-load stagger animation at 30ms per node (global index across all pipelines)
- Color-coded nodes by assigned agent role

### Directory Health Dashboard (Directory Health section)
- Four stat chips: Agents, Commands, Skills, Rules
- Timer-driven counter animation from 0 to target over 0.6s with easeOut curve
- `.contentTransition(.numericText())` for digit-rolling visual
- Reduce-motion support (jumps directly to final values)
- Relative timestamp with accent flash on update
- "Update Team Info" button with ProgressView loading state
- Inline error banner for script failures

### Native ManifestService
- Complete rewrite from Python script to native Swift using FileManager
- Parses `.claude/agents/*.md` files extracting name, description, and model from frontmatter
- Counts commands, skills, and rules from directory structure
- Builds WorkflowPipeline data from hardcoded pipeline definitions
- Actor isolation for thread safety
- Front-matter scan limit (50 lines) to handle malformed files
- `MockManifestService` with `@unchecked Sendable` and NSLock protection for tests

### TeamViewModel State Machine (SM-TEAM-001)
- Four states: `.idle`, `.loading`, `.loaded(AgentManifest)`, `.error(String)`
- Guard conditions on idle: checks toolkit path and manifest availability
- ManifestServiceProtocol injection via init for testability
- Real-time search filtering (`filteredAgents` computed property)
- Update cycle with `isUpdating` flag and `scriptError` propagation
