## Summary

Adds a fully functional Kanban board to Agile Maestro with 9 workflow columns, draggable filter bar, and card-to-tree navigation. Tasks flow through columns matching the review cycle: Backlog, Approved, In Progress, Code Review, QA, Security, Product Review, Human UAT, and Done.

---

## What's New

### Kanban Board View
- Horizontal scrolling board with 9 workflow columns
- Each column displays a header with title, count badge, and color-coded dot
- Empty column states with contextual messaging
- Security and Human UAT columns auto-hide when no epics are present

### Kanban Cards
- Cards show type icon, title, priority badge, and status accent bar
- Color-coded left accent bar indicates review stage
- Review stage and result badges on cards in review columns
- Single-tap navigates to the item in Tree view via `revealTask(_:)`

### Filter Bar
- Type segmented picker (All, Epics, Stories, Tasks, Bugs, TechDebt)
- Epic dropdown filter — scoped to epics present in the current session
- Filters apply live to all columns simultaneously

### Column Assignment Engine
- `KanbanViewModel` maps each task to the correct column based on status, review_stage, and review_result
- Cascade inheritance: tasks inherit epicId from parent stories for accurate epic filtering
- Two-pass transformation: build cards first, then cascade parent relationships

---

## Architecture Decisions

**Replaced `NavigationSplitView` with `HSplitView` in `TreeDetailView`.** The NavigationSplitView was causing title bar sliding, sidebar toggle injection, toolbar partitioning, and sidebar-divider bleed. HSplitView has zero window-chrome integration, resolving all of these issues.
